# Runtime dependencies for the Xenosaga III extractor kit. All of them are
# REQUIRED: the app bundles carry them, and the launchers (launch.command,
# launch.bat, launch.sh) install them into .venv/ on first run when the Python
# they find lacks any of them. No command falls back to a worse path when one
# is missing; `python cli.py self-test` fails instead.
#
#   python -m pip install -r requirements.txt
#
numpy>=1.21        # models (vif/pxy/xhr/gltf/models_sweep), fonts (font.py), pictures, region checks

capstone>=5.0      # `disasm` (MIPS R5900 disassembly + lui/addiu string xrefs)
fonttools>=4.40    # reading TrueType/OpenType fonts for new glyphs (glyphs.py, langpack.py)
uharfbuzz>=0.37    # text shaping for new scripts (glyphs.py, langpack.py `lang`)

#               commands list/dump/model/text-export do not need it)

#   Blender     `blend` (builds a .blend in the background); not needed otherwise
